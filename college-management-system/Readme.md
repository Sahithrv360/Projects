# College Management System

A web-based College Management System developed using **HTML, CSS, Bootstrap, JavaScript, Flask, and MySQL**.

The system provides a simple interface to manage students, faculty, courses, and attendance.

---

## 🚀 Features

### Student Management
- Add students
- View students
- Update student details
- Delete students

### Faculty Management
- Add faculty
- View faculty
- Update faculty details
- Delete faculty

### Course Management
- Add courses
- View courses
- Update course details
- Delete courses
- Assign faculty to courses

### Attendance Management
- Mark student attendance
- View attendance records
- Update attendance
- Delete attendance
- Calculate attendance percentage
- Generate attendance report

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

### Backend
- Python
- Flask
- REST API

### Database
- MySQL
